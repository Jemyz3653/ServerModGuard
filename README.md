# Server Mod Guard

Серверный мод для Minecraft 26.3, Fabric Loader 0.19.5 и Fabric API. Сообщение об обновлении клиента переведено на 15 языков. Мод читает язык игрока при подключении.

## Установка

Положи JAR и Fabric API в `mods/` выделенного сервера. После первого запуска появится `config/servermodguard/config.json`. Изменения в настройках применяются после перезапуска.

## Проверка клиента

Обычный Fabric-клиент не отправляет серверу версии установленных модов. Server Mod Guard проверяет серверный список `clientChecks` по каналам, которые уже объявляет проверяемый клиентский мод на этапе Fabric Configuration. Каналы должны меняться вместе с версией. При несовпадении или отсутствии нужного канала игрок получает список требуемых сервером версий и не входит в мир. Для модов без таких каналов, включая обычный ColoredM, точная проверка версий недоступна в серверном режиме.

Например, если мод `examplemod` объявляет каналы ниже, то для сервера с версией 1.1.0 клиент с одним каналом версии 1.0.0 получит сообщение про 1.1.0.

```json
"clientChecks": [
  {
    "mod": "examplemod",
    "channels": {
      "1.0.0": "examplemod:compat/v1.0.0",
      "1.1.0": "examplemod:compat/v1.1.0"
    }
  }
]
```

Указывай только каналы, зарегистрированные самим модом в фазе Configuration. Это проверка совместимости в обычных клиентах. Проверяемый клиент сам объявляет свои каналы.

## Автообновление серверных модов

1. Включи `updates.enabled` и добавь ID установленных модов в `mods` у нужного источника. Проверка запускается вскоре после старта сервера и повторяется раз в `checkMinutes`.
2. Источник по умолчанию — публичный JSON-каталог Prism. Для других источников укажи ссылку на JSON в GitHub либо `local:updates.json` для файла в `config/servermodguard/`. В каталоге можно указывать прямые ссылки на JAR с CurseForge, Modrinth и GitHub. API площадок и ключи не используются. Для проектов вне каталога Prism список версий и ссылки в каталоге поддерживает администратор.
3. Добавь команду применения обновлений **перед** существующей командой запуска сервера. Выполняй её из папки остановленного сервера.

```bash
java -jar mods/servermodguard-1.0.0+26.3.jar --apply
```

Новейшая совместимая стабильная версия скачивается в `config/servermodguard/pending/`. Мод сверяет размер, SHA-256, ID, версию и обязательные зависимости. Команда `--apply` ещё раз проверяет хеши, применяет подготовленные обновления и сохраняет старые JAR в `config/servermodguard/backups/`. Имена установленных файлов сохраняются. Сам Server Mod Guard обновляется вручную. Сервер автоматически не перезапускается, клиентские JAR тоже не обновляются.

Формат каталога совпадает с каталогом Prism. Пример:

```json
{
  "schema": 1,
  "projects": [
    {
      "id": "examplemod",
      "releases": [
        {
          "version": "1.1.0",
          "minecraft": ["26.3"],
          "loader": "fabric",
          "prerelease": false,
          "url": "https://github.com/example/examplemod/releases/download/v1.1.0/examplemod-1.1.0.jar",
          "sha256": "actual_sha256_of_the_jar",
          "bytes": 12345
        }
      ]
    }
  ]
}
```

Для Modrinth подходит прямая ссылка с `cdn.modrinth.com`, для CurseForge — ссылка на CDN `edge.forgecdn.net` или `mediafilez.forgecdn.net`. Хеш и размер должны соответствовать самому скачиваемому JAR. Доверяй каталогам, которые контролируешь или проверяешь.

## Сборка

JDK 25 и `./gradlew build`. В Windows PowerShell используй `.\gradlew.bat build`.
